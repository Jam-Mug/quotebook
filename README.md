"ЦИТАТНИК"

"ЦИТАТНИК" — одностраничный сайт: показывает по одной случайной цитате из выбранной категории (художники, писатели и т. д.)  плюс отдельную категорию для пользовательских цитат. На главной — лозунг, выбор категории, цитата и кнопка для смены цитаты; переключение сопровождается анимацией. Пользователи могут регистрироваться через отдельную кнопку (email, имя, фамилия, фото), после чего получают доступ к боковой панели со своими данными и списком своих цитат; все их цитаты автоматически попадают в отдельную категорию. Выдача цитат — рандомная, без отображения полного списка или истории просмотров.


Фронтенд‑разработчик:

реализовать логику отображения случайной цитаты по выбранной категории;
сделать анимацию смены цитаты (свайп);
организовать переключение между категориями;
реализовать регистрацию пользователя и показ боковой панели с его данными и цитатами;
обеспечить корректное отображение категорий;
предусмотреть адаптивное поведение и базовые пользовательские сценарии.

Бэкенд‑разработчик:

спроектировать и реализовать хранение данных (цитаты, категории, профили пользователей, пользовательские цитаты);
разработать API для получения случайной цитаты по категории и списка цитат пользователя;
реализовать функционал регистрации и авторизации пользователей;
